# Changelog

## 1.1.0

The file now also holds the whole topic list of each course you have studied: every topic's name and its prerequisites,
including topics you have not started. The graph uses it to draw a course in full, with all its topics and lines, as
Math Academy lists it. It is the course structure, the same for every learner, read from the request that already
reads your memory levels. No new requests and no new permissions. Files made by earlier versions still open as before.

## 1.0.0

First release. Exports completed tasks and Math Academy's own memory levels, remembers the last
export so updates fetch only what is new, and shows a badge when there is something to sync.
